# Physical Adapter Proof Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate exact validated JPEG/PLT files from a verified bundle and prove the PixCut protocol contract offline without accessing USB or advancing a visitor ticket.

**Historical scope.** This plan records the first offline dry-run implementation. The [physical adapter proof design](../specs/2026-11-28-physical-adapter-proof-design.md) also covers the later mock-tested transport-attempt module.

**Architecture:** Add a pure `@natcut/printer` workspace for file preparation and protocol planning, plus a create-only dry-run packet CLI. Keep the package transport-free and keep it out of `PhysicalExecutor` so no offline proof can synthesize fulfillment.

**Tech Stack:** TypeScript, Vitest, Sharp, existing domain/artifact verification, vendored pixcut tracer.

**Spec:** `docs/superpowers/specs/2026-11-28-physical-adapter-proof-design.md`

## Global Constraints

- Never enumerate USB, claim an interface, send a printer command, or access the physical printer.
- Never mutate Firestore, cloud storage, the worker journal, or public queue status.
- Do not implement `PhysicalExecutor` or add the dry-run path to a live worker entrypoint.
- Preserve receipt/profile evidence exactly and fail closed on every mismatch.
- Use `sprite`, never `plantemon`, in application text.
- Stop before a loaded-sheet test; it requires separate explicit approval.

## Review Focus

- Transparent or colored padding must become opaque white and retain exact 1216 × 2128 dimensions.
- The accepted cut margin must not be applied a second time when tracing the stored expanded mask.
- A complex image that remains over 1 MiB at quality 50 must fail without publishing a packet.
- Declaration lengths and upload chunks must bind to the exact generated bytes, with PLT before JPEG.
- A repeated run or interrupted publication must not overwrite or make a partial packet appear complete.
